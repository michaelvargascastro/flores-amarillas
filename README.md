# Web "Flores amarillas" para Kelly

## Fotos
Guarda tus 5 fotos dentro de la carpeta `imagenes` con estos nombres EXACTOS:

- foto1.jpg — comienzo / relación
- foto2.jpg — matrimonio
- foto3.jpg — foto de pareja actual
- foto4.jpg — foto especial para el mensaje final
- foto5.jpg — foto para el fondo de cierre

Si todavía no están, la web muestra marcadores donde irán las fotos.

## Probarla
Abre `index.html` en el navegador.

## Publicarla en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `imagenes`.
3. En Settings > Pages, selecciona Deploy from a branch.
4. Selecciona `main` y `/ (root)`.
5. Guarda. GitHub te mostrará la URL pública.

La web es responsive y está pensada principalmente para móvil.
